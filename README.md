Página de vendas do CPM-PRO (estática, para GitHub Pages).

- `index.html`, `style.css`, `site.js`: a página.
- `config.js`: links da lista de espera, checkout, contato e app (vazio = "em breve").
- `img/`: telas reais do app com dados fictícios.

## Pendências (decidir depois)
1. Link da lista de espera → `config.js` `waitlistUrl`.
2. Contato (e-mail e/ou WhatsApp) → `email`, `whatsapp`.
3. Plataforma de pagamento e links de checkout → `checkoutMensal`, `checkoutAteAProva`.
4. Preços definitivos e o que é grátis × pago.
5. Domínio próprio (custo ~R$ 40/ano) — também libera o e-mail de cadastro do app para os pais.
6. Ícone: estrela neutra ou desenho do aluno.
7. Depoimentos reais de pais.
8. Termos de uso e revisão legal (LGPD, nota fiscal, direitos sobre o conteúdo).
